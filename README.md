## 📖 About the Project

**Ra7alat** is a travel-focused mobile application that connects people with travel experiences and makes trip organization easier.

The platform allows users to explore available trips, book their preferred experiences, and create their own trips to share with other users. It provides a practical environment for travelers and trip organizers through an integrated platform combining trip discovery, booking, user profiles, and trip management.

## ✨ Key Features

1. **User Authentication & Profiles**
   - User registration and login.
   - Secure account data storage through Supabase.
   - Personal user profiles, picture management, and info management.

2. **Trip Discovery & Booking**
   - Explore and search available trips with filtering options.
   - View detailed trip information.
   - Book available trips directly through the application with a dedicated ticket.

3. **Trip Creation & Management**
   - Create and publish new trips, add photos/videos, and manage published items.
   - Save trips for later reference.

4. **Notifications & Verification**
   - In-app notifications for updates and activities.
   - Golden verification badge for eligible accounts.
